# My Tweaks Repository (iOS 12)

Репозиторий с твиками, протестированными и оптимизированными для iOS 12 (12.0–12.5.8).  
Ссылка на репозиторий: `https://username.github.io/my-tweaks-repo/`

> ⚠️ Важно: перед добавлением репозитория убедитесь, что на устройстве установлен Sileo, Zebra или Cydia.

## Совместимость

- **Целевая ОС:** iOS 12.x (12.0, 12.1, 12.2, 12.3, 12.4, 12.5, 12.5.7, 12.5.8)
- **Архитектура:** arm64 (iPhone 6s/7/8/X и новее), armv7s (старые устройства — если есть отдельные сборки)
- **Поддерживаемые устройства:** iPhone 6s, 7, 8, SE (1-го поколения), X, XS, XR; iPad Air 2, iPad mini 4, iPad Pro (1‑го и 2‑го поколения)

## Как добавить репозиторий

### Sileo / Zebra
1. Откройте Sileo или Zebra → вкладка **Sources** (Источники).
2. Нажмите **+** или **Add Source**.
3. Вставьте ссылку: `https://github.com/magomedildarov64-coder/RenG1n_IOS12`.
4. Подтвердите добавление.
5. Обновите источники (**Refresh**).
6. Найдите твик в поиске или в категории **Installed / New**.

### Cydia
1. Откройте Cydia → вкладка **Sources**.
2. Нажмите **Edit** → **Add**.
3. Вставьте ссылку: `https://github.com/magomedildarov64-coder/RenG1n_IOS12`.
4. Нажмите **Add Source**, затем **Return**.
5. Дождитесь обновления списка пакетов.

- **iOS 12** (любая версия из списка выше).
- **Джейлбрейк** (checkra1n, unc0ver, Chimera и т.п.).

## Установка и обновление

1. Добавьте репозиторий (см. раздел «Как добавить»).
2. Найдите нужный твик в поиске.
3. Нажмите **Install**, затем **Confirm**.
4. После установки перезагрузите SpringBoard (в Sileo/Zebra обычно есть кнопка **Restart SpringBoard**).
5. Для обновления: **Sources → Refresh**, затем в списке установленных твиков нажмите **Update**.

## Известные проблемы и решения (iOS 12)

| Проблема | Решение |
| --- | --- |
| Твик не появляется в поиске | Проверьте, что репозиторий добавлен и источники обновлены (**Refresh**). |
| Ошибка установки (Sub-process dpkg returned an error) | Убедитесь, что зависимости (например, `preferenceloader`) установлены. Перезагрузите устройство. |
| Сбои SpringBoard после установки | Удалите твик, перезагрузите устройство, установите заново. Если повторяется — сообщите в Issues. |
| Не работает на iOS 13+ | Эти сборки предназначены только для iOS 12; для более новых версий нужны отдельные пакеты. |
